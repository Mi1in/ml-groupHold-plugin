# ml-sgh-plugin

云崽（Yunzai-Bot）插件：统计**本群成员**的角色持有率，支持原神与崩坏：星穹铁道。

> 本插件由 AI 辅助编写，代码与文档按 [MIT](LICENSE) 协议开源。

- 总览：全群角色持有率排行，可按星级、指定命座筛选
- 详情：单角色的等级、命座 / 星魂、武器 / 光锥、圣遗物 / 遗器分布
- 旅行者七元素分别统计
- 群名 + 打码群号，1.5 倍高清出图

## 指令

| 指令 | 说明 |
| --- | --- |
| `#群角色持有率` | 默认五星角色持有率 |
| `#群全部角色持有率` / `#群五星角色持有率` / `#群四星角色持有率` | 按星级筛选 |
| `#群二命角色持有率` | 按指定命座排序（`0`~`6` / `一二三四五六` / `满`） |
| `#群满命角色持有率` | 满命持有率 |
| `#群甘雨持有率` | 单角色详情 |
| `#冰主持有率` | 旅行者指定形态 |
| `*昔涟持有率` | `*` 前缀 = 星穹铁道，其余指令同上（星魂 / 光锥 / 遗器内外圈） |

指令里的「群」字可以省略不写，例如 `#甘雨持有率`、`#角色持有率` 与带「群」的写法等效。

## 安装

前置：Yunzai-Bot V2 / V3、[miao-plugin](https://github.com/yoimiya-kokomi/miao-plugin)、puppeteer 渲染器。

```bash
cd <云崽目录>/plugins
git clone https://github.com/Mi1in/ml-sgh-plugin.git ml-sgh-plugin
```

重启云崽即可。角色数据、立绘、图标与字体均由本机已安装的 miao-plugin 提供，**装好 miao-plugin 即可使用，无需额外下载资源包**；本插件不附带、不内置、不镜像任何角色数据或游戏素材。

## 资源说明

- 头图里的元素 / 命途 / 武器图标是可选增强：运行时依次探测本机 miao 资源与本插件可选的 `resources/icons/`，命中就用图标，全部缺失自动降级为文字标签，不影响出图。图标文件不在本仓库内，也已被 `.gitignore` 排除，需要的话请自行放到本机对应目录。
- `resources/sr-face.json` 是星铁头图的逐角色标定（把角色头部对齐头图中线），针对当前立绘标定，换资源后可能偏移。未收录的新角色按「立绘中线往上 1/3」兜底；需要精调时在 json 中补一行 `"角色名": 锚点值`，需额外放大时写 `{"a": 锚点, "z": 缩放}`。

## 数据来源

读取本机 `data/PlayerData/<game>/<uid>.json`，通过 miao 的 `ProfileRank.getUserUidMap` 把统计范围限定在本群成员。纯本地读取，不联网上传任何数据。
